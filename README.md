# Flappy Pokemon

**Flappy Pokemon** is a 2D Unity game where you play as a Chrizard and jump over hurdles to score points. Unlock new chrizard skins and try to beat your high score!

---

## 🎮 How to Play

- Click or tap to make the Chrizard **jump**
- Avoid hitting the **hurdles** or **ground**
- Pass hurdles to **score points**
- Unlock **Blue Charizrd** at 10 points 

---

## 🔧 How to Run the Game

1. Open the project in **Unity 2021 or newer**
2. Go to the `Scenes` folder
3. Open `SmpleScene.unity`
4. Click **Play** to start

---

## 🧠 Features

- Easy tap-to-jump controls
- High score tracking using `PlayerPrefs`
- Unlockable skins
- Simple UI management
- Adjustable sound settings

---

## 💡 Scripts Overview

- `GameManager.cs` – Controls the overall game logic
- `HurdleController.cs` – Moves and resets the hurdles
- `DragonManager.cs` – Handles switching between dragons
- `UIController.cs` – Manages UI screens and volume
and more
---

## 📦 OOP Concepts Used

- **Encapsulation** – Variables and methods are kept private where needed
- **Abstraction** – Managers handle logic cleanly
- **Inheritance** – MonoBehaviour is inherited for Unity behavior
- **Composition** – Managers use other classes to split responsibilities
